# 国考省考选岗匹配器（本地版）

这是参考页面的本地离线版，数据、专业目录、匹配规则和页面交互均内置在 `index.html` 中。

## 启动

在此文件夹打开终端后运行：

```powershell
python -m http.server 8787
```

然后访问 <http://localhost:8787/>。

## 数据范围

- 国考：2022–2026
- 省考：广东 2022–2026、江苏 2023–2026、河南 2022–2026、四川 2025–2026
- 来源：国家公务员局及各省公务员主管部门公开的招考简章/职位表；部分历史年度使用政府网站镜像及公考机构同步的官方版本交叉核对。
- 进面分：国考使用各年度官方首批面试人员名单归并；省考公开不完整时按页面显示为未公开。

页面只在浏览器本机计算，填写的画像保存在本机浏览器中。
